# SIC Editor-Webdemo

Eine eigenständige, minimale Texteditor-Anwendung für SIC-Quelltext.

## Start

```bash
make editor
```

Danach den Editor unter <http://127.0.0.1:8001> öffnen.

Der Inhalt bleibt während der Browser-Sitzung reaktiv erhalten. Speichern,
Dateien öffnen, Kompilieren und Syntax-Highlighting folgen später.
